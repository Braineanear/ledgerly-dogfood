# RFC 0002: Product SKU normalisation

Status: accepted

## Decision

A SKU is stored upper-case with surrounding whitespace removed.
The helper `normalize_sku(sku)` in `shared/src/ledgerly_shared/sku.py` returns that form.
It raises `ValueError` for an empty SKU after trimming.

## Tests

Tests live in `shared/tests/test_sku.py` and cover trimming, upper-casing and the empty case.
